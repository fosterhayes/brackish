Add it in Gmail

  1. On a computer, tap Copy signature above.
  2. In Gmail, open Settings (gear) → See all settings → General → Signature.
  3. Click Create new, name it "Brackish," and paste into the box.
  4. Under Signature defaults, choose it for new emails and replies, then Save Changes at the bottom.

Add it in Outlook or Apple Mail

  1. Outlook: Settings → Mail → Compose and reply → Email signature, then paste.
  2. Apple Mail (Mac): Mail → Settings → Signatures, click +, paste, and uncheck "Always match my default message font."
  3. iPhone Mail strips formatting from pasted signatures, so set it on your computer and send from there for prospect emails.
